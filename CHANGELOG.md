## [0.0.1] - 2026-11-17

### Added

- **JJ Lens Studio**: Visual commit graph with drag-and-drop rebase / squash / merge / parallelize and Before/After previews, a revision inspector (description, file-level split / move / discard, bookmarks, evolution log), an operations timeline, illustrated concepts, a command atlas, recipes, a Git comparison table, and a revset cheat sheet.
- **Command Learning Bar**: Shows the underlying `jj` CLI command and option explanations behind every action with one-click copy.
- **Bilingual UI**: Full Japanese and English UI switcher inside JJ Lens Studio.
- **Sidebar & Status Bar**: `Working Copy (@)` tree view, `Quick Actions & Guide` tree view, and `@` status bar item.
- **Jujutsu Commands**: `openStudio`, `new`, `newMerge`, `commit`, `edit`, `describe`, `abandon`, `squash`, `absorb`, `split`, `duplicate`, `rebase`, `parallelize`, `bookmarkSet`, `bookmarkDelete`, `gitFetch`, `gitPush`, `gitPushRevision`, `undo`, `setRevset`, `openDiff`, `openFile`, and `restoreFile`.
